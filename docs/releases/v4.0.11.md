RouteX 4.0.11 — Stable connection under heavy load, compact Subscriptions

- No more false "VPN down" when the link is busy: a big download (for example a game loading avatars) delayed the health probe, and RouteX restarted the tunnel or switched servers although it was working. Data coming back through the server now counts as proof the tunnel is alive, and while the link is busy the tunnel gets 30 s instead of 7 s before a failover. A really dead VPN still fails over.
- Subscriptions autoswitch no longer changes server while the current one is still sending data.
- No more planned restarts while you use the tunnel: the 10-minute domain re-apply no longer restarts VLESS / VMess / Trojan tunnels, and the return to the primary VPN, the return to the chosen server and the background server test wait until the tunnel is idle.
- A crashed xray / sing-box / WireSock in VPN Only mode restarts at once instead of after 30 s.
- Subscriptions: one-line server rows and a slimmer header — about three times more servers fit on one screen.

New settings in settings.ini: BusyFailoverSec (30) and BusyRxKBps (200).

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
