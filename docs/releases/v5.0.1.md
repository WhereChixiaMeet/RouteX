RouteX 5.0.1 — Routing card as before

- Routing: the connection card is back exactly as it was in 4.0 — status, details, latency line, Backup config, Primary config and Connection mode. The VPN / Direct tiles from 5.0.0 are removed.
- Everything else from 5.0 stays: the new title bar with Back / Forward, no window inside a window, compact settings, the sidebar without gaps, no "No servers found", the log in your accent color and grey buttons on dark themes.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
