RouteX 5.1.2 — Backup config can be changed

- Routing → Backup config: the selector is always available, also while connected. Choosing a config turns the backup on, "None" turns it off. Before, it stayed greyed out until a separate "Backup VPN" switch in Connection settings was turned on.
- Tunnel Configs → Backup now really turns the backup on (before, it only remembered the config).
- The backup config can no longer be the same as the primary one; making the backup config primary clears the backup.
- A new backup config is used from the next switch to backup; the current connection is not interrupted.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
