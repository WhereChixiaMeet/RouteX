RouteX 5.1.0 — AmneziaWG

AmneziaWG
- New tunnel type: AmneziaWG. Copy a vpn:// key from the Amnezia app (your server → Share → AmneziaWG), then Tunnel Configs → New from link, and paste it. The tunnel works like the others: Primary / Backup, VPN Only, DPI/VPN, Include / Exclude lists, kill switch and failover.
- All AmneziaWG obfuscation settings from the key are kept as they are (Jc, Jmin, Jmax, S1–S4, H1–H4 including ranges, I1–I5), so the traffic looks the same as from the Amnezia app. AmneziaWG 1.0, 1.5 and 2.0 servers are supported.
- Site names are resolved inside the tunnel by the DNS servers of the key, not by your provider. The local port of the tunnel accepts only RouteX (login per start), so other programs on the PC cannot use it or find an open proxy.
- The AmneziaWG core (mihomo, MetaCubeX) and the TUN core (sing-box) are downloaded automatically when you add the first key. WireSock is not needed for AmneziaWG.
- The tunnel can be edited as text, like WireGuard.
- Keys of the Amnezia service (Premium / Free) contain no tunnel inside and are explained instead of failing silently.

Other
- Include / Exclude entries with a space in the name (for example "Yandex Music.exe") no longer break the TUN mode of subscriptions and VLESS tunnels.
- Existing WireGuard (WireSock), VLESS, VMess and Trojan tunnels and subscriptions work exactly as before.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
