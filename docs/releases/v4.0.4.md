RouteX 4.0.4 — Background, icon and accent colour

- **Fixed: the background image could not be set.** The file dialog now opens outside the WebView2 message handler (it could open behind the window or lock the interface), the classic interface is no longer rebuilt in the background on every change, and WebP images are accepted. An image that cannot be read now shows a message instead of failing silently.
- **Fixed: a custom application icon did not show in the new interface.** The sidebar logo now uses the chosen icon, together with the window and tray icons. "Reset icon" brings the RouteX logo back.
- **Accent colour everywhere:** the VPN line on the Monitor chart, its legend and the sidebar VPN dot follow the chosen accent (a custom palette with its own VPN colour keeps it). Buttons, switches, fields and cards get a faint tint of the accent.
- The Monitor chart grid shows whole numbers on every line.
- Other file dialogs (import/export, log folder, DPI folder, entry icons, updates) also open outside the WebView2 handler.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
