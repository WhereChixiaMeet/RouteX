RouteX 5.1.1 — Updates for the AmneziaWG core

- The AmneziaWG core (mihomo) can be updated from RouteX: Settings → Updates → "mihomo (AmneziaWG)" shows the installed and the latest version and has an Update button.
- New mihomo versions are checked together with xray and sing-box (same schedule and the same switch), with the usual notification and the badge on Settings.
- The update is safe: the file is downloaded first, a running AmneziaWG tunnel is interrupted only for a moment and connected again. The previous version is kept as mihomo.exe.old; if the new one does not start, RouteX puts the previous one back by itself.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
