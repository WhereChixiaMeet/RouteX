RouteX 4.0.17 — No false holes in the Monitor chart

- Monitor: a single failed probe (one request that timed out) used to break the latency line, so a stable connection looked like it kept dropping. It is now a small yellow mark on an unbroken line. The line only breaks for a confirmed outage, when RouteX really switches to "VPN unavailable".

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
