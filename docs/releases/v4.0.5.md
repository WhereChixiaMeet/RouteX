RouteX 4.0.5 — Fixed header, scrolling lists

- Routing: the page header, connection card and connection settings stay in place; only the Include, Strict and Exclude lists scroll, each on its own.
- Subscriptions: the header, toolbar, tabs and search stay in place; only the server table scrolls, and its column headers stay visible.
- On a very small window the page still scrolls as a whole, so nothing gets cut off.
- Release builds now check that the interface script parses before publishing.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
