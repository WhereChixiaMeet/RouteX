RouteX 4.0.3 — Working update buttons and interface audit

- **Fixed: the update buttons in Settings → Updates did nothing useful.** All five buttons sent the same "check" command, so "Update zapret", "Update xray" and "Update sing-box" never installed anything and "Check RouteX updates" stayed silent. Each button now does its own job, and every row shows the installed version and whether a newer one is available.
- **Fixed: a new RouteX version could not be installed from the new interface.** The "Update to vX" button lived only in the hidden classic sidebar. It is back at the top of the sidebar and in Settings → Updates.
- Tests: the "VPN channel" / "Direct channel" checkboxes no longer show an "Unsupported setting" error.
- Accessibility: every checkbox, switch and field in Settings, DPI and TG Proxy now has a name for screen readers (taken from its row title), and text areas and other focusable elements show the same focus ring as buttons.
- Audit: every button, switch and selector of the new interface was checked against the app's handlers; no other unwired controls were found.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
