RouteX 4.0.15 — TG Proxy shows who holds its port

- TG Proxy: when the port is used by another program, the error now names that program and its PID (for example "tg-ws-proxy.exe (PID 1234)"). Restart can only free RouteX's own socket, so close that program or choose another port in TG Proxy settings, then press Restart.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
