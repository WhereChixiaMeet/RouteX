RouteX 5.0.3 — Fewer false disconnects, cleanup after crashes, safer saving

Connection
- VPN Only: a short pause of the checker no longer cuts off games and calls. While the tunnel is still running, apps are not blocked in the firewall; the kill switch is applied only when the tunnel is really restarted (30 s without an answer) or has stopped.
- The "link is busy" protection (longer wait before a failover, postponed planned restarts) now works even when the speed monitor is switched off in Settings.
- Waking the PC from sleep no longer triggers an immediate failover or a server switch: the network gets time to come back.
- After a crash or closing RouteX from Task Manager, leftover wiresock-client, sing-box and xray from the previous run are closed before a new start. Before, the new tunnel could not start and the old TUN kept sending traffic to a dead port.
- Subscriptions: if the chosen server fails to start, the system proxy and TUN are switched off together with it (before: no internet in browsers while the status said "Off"). A server that xray refuses is skipped by autoswitch instead of being picked again.
- Exit: the tunnel, firewall rules and system proxy are always removed in order. Closing RouteX in the middle of a reconnect could leave a firewall rule or the proxy behind.
- DPI: winws that stops at once is noticed and restarted; if it keeps stopping, DPI is switched off with a message in the log instead of showing "DPI" with nothing running. Deleting the active strategy selects another one.

Data
- settings.ini, servers.json and subscriptions.json are written through a temporary file: a crash or power loss during saving no longer leaves an empty or cut file. One damaged entry no longer drops the whole server list.
- Subscription update keeps the selected server, favorites and traffic statistics when the provider only renames a server (remaining traffic, expiry date in the name).
- A subscription can be updated when all servers are down: the request is retried without the RouteX system proxy.
- Backup now includes your DPI domain lists from the zapret folder.
- Core updates (xray, sing-box): the download happens first, the connection is interrupted only for the installation, and not at all when the core is already current. A core in use by the VPN tunnel gives a clear message.
- Old update folders (copies of the executable and of the settings) are removed after 3 days.

Interface
- Moving or resizing the window, or dragging the widget, no longer redraws the whole page (menus closed, lists jumped to the top).
- Log page: new lines appear as they are written.
- Servers table: no demo values for a missing country or address, no dangling separator, speed is rounded.
- "From link" on a WireGuard tunnel explains what to do instead of silently doing nothing; a new tunnel from a link never replaces an existing one with the same name.
- Lower CPU and disk use while the window is open.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
