RouteX 4.0.10 — Recent apps in the "+" picker

- "+" in Include / Strict VPN / Exclude opens the app picker again, as in the old interface: the recently added apps come first (marked "recent"), then the running processes with icons and TCP counts.
- Search, "With connections only", select several rows with a click, double-click adds at once; a manual field still takes a process name, path, domain or IP.
- Apps already in the list are not offered again.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
