RouteX 4.0.12 — TG Proxy switch, real server IP in Monitor

- TG Proxy: the switch now follows the setting. Before, it showed whether the proxy was running, so after a failed start (for example a busy port) it showed OFF while TG Proxy was still on, and it could be neither turned off nor retried. A dot now shows running (green), starting (yellow) or failed (red), with the start error under it.
- Monitor: the VPN card shows the server you actually connect to next to the exit IP that websites see, and says why they differ: Cloudflare WARP on the server, IPv6, or a probe that went around the tunnel.
- Monitor: the old server's IP is no longer shown after switching to another server or tunnel.
- Monitor: probe intervals are randomly spread by up to 25 % (never faster than the set rate), so the traffic has no exact clockwork pattern.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
