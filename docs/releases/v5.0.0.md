RouteX 5.0 — New window, Monitor-style Routing, compact interface

- New window: no more window inside a window. The system title bar and the frame around the interface are gone; RouteX has its own title bar with Back / Forward on the left, "RouteX" in the middle and Minimize / Maximize / Close on the right. Drag it to move the window, double-click to maximize. Back / Forward also work with Alt+← / Alt+→ and the mouse's side buttons. Resizing, snapping and Win+arrow keys work as before.
- Routing: the connection card shows the connection like the Monitor page — VPN and Direct tiles with latency, IP and a small live graph, plus the details (protocol, server, uptime, probe) as short tags. The card keeps its size; Backup config, Primary config and Connection mode stay where they were.
- Settings: much less empty space — rows, cards and the font table are compact, and the fields sit next to their labels.
- Sidebar: no gaps between the menu groups.
- Subscriptions: an empty list no longer shows "No servers found".
- Log: the log box uses your accent color.
- Dark themes: buttons are neutral grey instead of bluish.

Close RouteX before replacing the executable. Keep your config and core folders. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
